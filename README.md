# SWO Pulse v1

PHP/cron automation engine. Detect → generate fix → request approval → apply via MCP bridge → verify outcome.

## Status

**Week 1 — Spine + MCP Integration Layer** complete. Detection (Week 2), fixers (Week 3), verifiers (Week 4) not yet built.

## Stack

- PHP 8.x, SQLite 3, cPanel cron
- No SaaS dependencies. No frameworks. Vanilla curl for HTTP.
- Deployed at `pulse.safariweb.online`

## Layout

```
.
├── install.php          one-file installer with §A1 gate
├── app/
│   ├── bootstrap.php    single require point for cron/public/installer
│   ├── core/            spine + MCP integration
│   ├── config/          generated by installer (gitignored)
│   └── jobs/            agent modules (Week 2+)
├── cron/
│   ├── tick.php         every 5 minutes
│   └── heartbeat.php    daily 00:01 SAST
├── public/              admin UI (login + placeholder dashboard)
├── data/                SQLite DB + logs (gitignored, blocked by .htaccess)
└── scripts/smoke.php    local Week-1 spine test
```

## Install (cPanel)

1. Upload repo to the document root of `pulse.safariweb.online`.
2. Visit `https://pulse.safariweb.online/install.php` in a browser.
3. Complete the three steps: admin user → first site + mail → §A1 gate.
4. Installer renames itself to `install.php.done` on success.
5. Add cron jobs in cPanel:
   ```
   */5 * * * * php /home/USER/pulse.safariweb.online/cron/tick.php >> /home/USER/pulse.safariweb.online/data/logs/cron.log 2>&1
   1 0 * * *   php /home/USER/pulse.safariweb.online/cron/heartbeat.php
   ```
6. Log in at `/login.php`.

## Anti-orphan rules (enforced in code)

- **A1** — install.php blocks until first site + test tick + test email pass
- **A2** — `findings.recommendation NOT NULL`; `ApplyRouter` rejects findings without `fix_payload_json`
- **A3..A6** — weekly digest, self-assessment, kill criterion, applier-fit — wire into Week 4 reporting

## MCP integration

`app/core/MCPClient.php` is a generic JSON-RPC 2.0 client for any MCP bridge.
`app/core/ApplyRouter.php` routes an approved finding to the site's bridge, records the application in `fix_applications`, and schedules `+1h / +24h / +7d` verifications.

```php
$result = MCPClient::call(
    'https://aerotel.co.za/mcp/',
    $bridgeKey,
    'cpanel_list_projects',
    []
);
$text = MCPClient::extractText($result);
```
