# Competitor Hotel Selection Tool

A simple, interactive tool for selecting competitor hotels with autocomplete and suggestion features.

## Features

- **No Default Hotels**: Start with a clean slate - no pre-selected competitors
- **Smart Suggestions**: Get AI-suggested competitor hotels that you can approve or reject
- **Autocomplete Search**: Type to search hotels with real-time suggestions
- **Keyboard Navigation**: Use arrow keys, Enter, and Escape for efficient selection
- **Visual Feedback**: Clean, modern interface with intuitive interactions

## How to Use

1. **Open the Application**: Open `index.html` in your web browser
2. **Review Suggestions**: Look at the suggested competitor hotels and either approve or reject each one
3. **Search Manually**: Type in the search box to find specific hotels - suggestions appear as you type
4. **Select Hotels**: Click on autocomplete suggestions or use keyboard navigation (arrow keys + Enter)
5. **Manage Selection**: Remove hotels from your selection if needed
6. **Save**: Click "Save Selection" when you're done

## Files

- `index.html` - Main application structure
- `styles.css` - All styling and animations
- `hotelData.js` - Sample hotel database
- `app.js` - Core functionality (autocomplete, selection, state management)

## Technology

Built with vanilla JavaScript, HTML, and CSS - no frameworks required!
